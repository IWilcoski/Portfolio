Wish Upon a Star

Engine/Language: Renpy, Python

Itch.io Page: Wish Upon a Star


My Role

I was the only programmer for this project, and implemented a hub and spoke narrative approach, with character approval ratings and various endings.

Game Summary

Wish Upon a Star was my first collegiate game jam project and first experience with Renpy, produced over 48 hours. The game is a visual novel where you meet four characters from worlds with different genres and art styles. Gameplay is mostly dialog and choices, though it had an approval tracker for each character that determined who you could get endings with.

This project had difficulties in implementation time, as we had a short amount of time and a lot of dialog with different variations. The project struggled because dialog was written outside of the Renpy code, and was written and implemented up to the last hour. In addition art was submitted last second or after the deadline, so a character was cut in the original build and we had no playtest time.
